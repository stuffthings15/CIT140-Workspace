# CIT 140 — Systems Analyst Portfolio

**Curtis Loop** · Introduction to Systems Analysis and Design · Weeks 1–8

This repository holds the case investigations completed for CIT 140. Each week produced one artifact, stored in its own folder with any supporting evidence and the mission receipt for that week. Canvas holds the official submissions, dates and grades.

## Cases in this portfolio

Two separate fictional cases run through the course. They are kept apart deliberately; findings from one do not carry to the other.

| Case | Setting | Weeks |
|---|---|---|
| **Meridian Forge Robotics** | Robotics QA cell; a retired test running on MR-17 | 1, 2, 3, 7 |
| **Cedar Junction** | Civic operations and clinic appointments | 4, 5, 6 |

## Known gaps

Recorded here rather than left implicit:

- **Mission receipt PDFs for Weeks 1–4 are not stored in this repository.** The Week 1 receipt code is on record; the Week 2–4 codes were submitted directly in Canvas at the time and the PDFs were not retained here.
- **Folder structure is not uniform.** Weeks 1–4 use the folder layout each assignment specified at the time; Weeks 5–7 use `Artifact/`, `Evidence/` and `Receipt/`. Earlier folders are left unchanged because their file links were already submitted in Canvas.
- **Week 4 has no structured JSON export** in the repository; only the PDF artifact was required at submission.

## Notes for a reader

Each weekly artifact reports what the supplied case records support and marks what they do not. Several findings are deliberately left open: a flagged record means something needs checking, not that a fault or a cause has been established. The two cases are unrelated, and no finding from one should be read against the other.
